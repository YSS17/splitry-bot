Splitry

Divisão de despesas via WhatsApp

1. Sobre o Splitry

O Splitry é um serviço de divisão de despesas que funciona via WhatsApp e página web. Permite que grupos de pessoas registrem gastos, dividam valores e controlem pagamentos de forma simples.

2. Dados que coletamos

Para o funcionamento do serviço, coletamos:

  • Número de telefone do WhatsApp
  • Nome fornecido pelo usuário
  • Mensagens enviadas ao bot para processar comandos
  • Valores e descrições de gastos registrados
  • Imagens de comprovantes de pagamento enviadas voluntariamente

3. Como usamos os dados

Os dados coletados são usados exclusivamente para:

  • Identificar o usuário dentro de um grupo de rateio
  • Registrar e dividir gastos entre os membros
  • Enviar notificações sobre novos gastos e pagamentos
  • Exibir o saldo e histórico de transações

Não vendemos, compartilhamos ou usamos seus dados para fins publicitários.

4. Armazenamento

Os dados são armazenados em banco de dados seguro (PostgreSQL) hospedado na Railway. Comprovantes de pagamento são armazenados no servidor do serviço.

Os dados são mantidos enquanto o usuário utilizar o serviço. Não realizamos backups externos dos dados pessoais.

5. WhatsApp e Meta

O Splitry utiliza a WhatsApp Business API fornecida pela Meta. As mensagens trocadas com o bot seguem também as políticas de privacidade do WhatsApp e da Meta Platforms.

Não armazenamos o conteúdo completo das conversas — apenas os comandos necessários para o funcionamento do serviço.

6. Seus direitos

Você pode a qualquer momento:

  • Solicitar a exclusão dos seus dados enviando uma mensagem ao bot com "excluir minha conta"
  • Parar de usar o serviço simplesmente não interagindo mais com o bot

7. Contato

Dúvidas sobre esta política podem ser enviadas diretamente pelo WhatsApp para o número do Splitry.
